# Social Media Automation - Runtime Dependencies

# Only what the application actually imports. Versions are pinned to the ones
# proven working in local development.
#
# This file was previously aspirational: it pinned packages the code never
# imported (pandas, numpy, nltk, anthropic, psycopg2, aiohttp, marshmallow,
# sentry, black, flake8, ...) at versions that predate Python 3.12. Those old
# releases have no 3.12 wheels, so pip fell back to building from source and

#
# Development and test-only packages live in requirements-dev.txt so a deploy
# never builds them.
